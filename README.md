# Business — India Edition

A local pass-and-play property trading board game for 2–6 players, built with React, TypeScript, and Vite. All game logic runs in the browser and saves automatically to local storage.

## Run locally

```sh
npm install
npm run dev
```

## Game

Set up players and rules in the lobby, then take turns rolling, buying properties, paying rent, drawing cards, and managing your assets. Use the resume option to continue a saved match on the same device.
